# Frontend

## Локальная объединённая версия

Запускайте `npm.cmd run dev` из корня репозитория или из этой папки: в обоих случаях поднимаются backend и сайт. Дождитесь сообщения «SteppeX готов».
Сайт доступен на http://127.0.0.1:5173, API проксируется на 127.0.0.1:3002.
`npm.cmd run build` в этой папке проверяет TypeScript и собирает frontend; `npm.cmd run preview` показывает уже собранный сайт и требует отдельно запущенного backend.
После изменений нужна пересборка и обновление страницы, HMR в локальном launcher не используется.
Реализовано: React + TypeScript, CSS команды и fetch; разделы ниже сохранены как исходный план команды, а не перечень завершённых функций.
Актуальные возможности и инструкция: [README локальной сборки](../README.md).

## Назначение
Фронтенд-часть отвечает за интерфейс симулятора: выбор решений, проверку бюджета, визуализацию итогового score и объяснение AI-результата.

## Стек
- React + TypeScript
- Vite
- Tailwind CSS
- Recharts
- Axios

## Основные задачи
- форма выбора 5 решений по направлениям;
- экран “бюджет и остаток”;
- карточки мероприятий с ценами и эффектом;
- итоговый dashboard с Astana Quality of Life Score;
- AI-объяснение результата в человекочитаемом виде;
- сравнение сценариев между командами (если будет добавлено).

## Ключевые экраны
- Главная страница симулятора
- Панель управления бюджетом
- Страница результатов
- История сценариев

## Принцип работы
Frontend получает состояние и список мероприятий с бэкенда, отображает их пользователю, собирает выбранные ответы и отправляет на API для расчёта итогов.
