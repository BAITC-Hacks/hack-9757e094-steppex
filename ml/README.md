# Machine Learning

## Назначение
ML-модуль отвечает за оценку сценария, агрегирование показателей и формирование AI-объяснений на основе выбранных решений.

## Стек
- Python
- scikit-learn
- pandas
- numpy
- Jupyter / notebooks (для экспериментов)
- OpenAI-compatible API или локальная логика для генерации объяснений

## Основные задачи
- подготовка синтетического датасета;
- расчёт Astana Quality of Life Score;
- определение влияния каждого решения на показатели по районам;
- генерация сильных сторон, рисков и рекомендаций;
- моделирование сценариев при изменении набора решений.

## Подход
- Создаётся модель оценки качества жизни на основе взвешивания ключевых факторов: транспорт, зелёные зоны, инфраструктура, безопасность, сервисы.
- Каждое решение изменяет соответствующие показатели и добавляет эффект на итоговый score.
- AI-часть может быть реализована как генератор текста по итогам расчёта, а не как тяжёлая нейросеть.

## Результат ML-модуля
- score по итоговому сценарию;
- список ключевых факторов;
- сильные стороны;
- риски и компромиссы;
- предложения по улучшению сценария.

## Реализация в `simulator.py`

Числовой расчёт детерминированный: обучающий датасет для ML-модели в задаче не задан, поэтому модуль применяет точные эффекты мер, лаги, синергии, несовместимости и формулу из датасета организаторов. Текстовое объяснение строится по рассчитанным значениям.

Запуск из папки `ml/`:

```python
from simulator import simulate_scenario, explain, example_scenario, simulate

result = simulate(example_scenario())
print(explain(result))

# Формат решений для общего JSON/API-контракта:
payload = simulate_scenario([
    {"measureId": "M7", "districtId": "nura"},
    {"measureId": "M8", "districtId": "nura"},
    {"measureId": "M10", "districtId": "nura"},
    {"measureId": "M12"},
    {"measureId": "M5", "districtId": "saryarka"},
])
```

Публичные функции: `validate(decisions)`, `simulate(decisions)`, `simulate_scenario(decisions)`, `explain(result)`. Не размещайте API-ключи в ML-папке или браузере.
